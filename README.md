# 🏋️ Academia Backend

Sistema de gerenciamento de academia desenvolvido em Python com foco no estudo de Programação Orientada a Objetos (POO).

## 📚 Sobre o projeto

Este projeto foi desenvolvido como forma de colocar em prática conceitos de Programação Orientada a Objetos estudados durante meus estudos de Python.

O sistema permite realizar o gerenciamento básico de alunos e professores através de um menu no terminal.

## ⚙️ Funcionalidades

### Alunos
- Cadastrar aluno
- Listar alunos
- Buscar aluno por matrícula
- Editar dados do aluno
- Excluir aluno
- Geração automática de matrícula

### Professores
- Cadastrar professor
- Listar professores
- Buscar professor por ID
- Editar dados do professor
- Excluir professor
- Geração automática de ID

## 🧠 Conceitos praticados

- Programação Orientada a Objetos
- Herança
- Encapsulamento
- `@property`
- Getters e setters
- Validação de dados
- Tratamento de exceções
- CRUD
- Versionamento de código com Git
